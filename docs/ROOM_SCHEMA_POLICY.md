# Room schema policy

OwnPlay keeps exported Room schemas in `app/schemas` under source control.

Rules:

- `OwnPlayDatabase.exportSchema` remains enabled.
- Room schema output is configured through the Room Gradle plugin.
- Every database version must have its generated schema JSON committed before merge.
- Database version bumps require an explicit migration or auto-migration path plus migration validation.
- Production database creation must not use destructive migration fallback.
- Instrumentation migration tests read the same exported schema history.
- CI compiles the migration harness and uploads the generated schema directory for audit.

Schema JSON must be generated by Room tooling; do not hand-author or normalize it manually.
