Implemented contract
- Existing Live background behavior is preserved on Mobile and TV.
- Outside Picture-in-Picture and outside configuration changes, Mobile Movie and Series Episode playback now returns SUSPEND_AND_RETAIN_SURFACE from the existing Activity lifecycle policy.
- MainActivity therefore reuses its existing surface suspension path and PlaybackController.suspendForBackground().
- PlaybackController already preserves position for non-Live media and resumeAfterBackground() restores the suspended request using that position.
- A playback session that was paused before suspension remains paused after resume because PlaybackController retains playWhenReady state.
- Picture-in-Picture continues to own playback and therefore returns NONE from the background policy.
- Configuration changes continue to return NONE from the background policy.
- Idle and Failed states do not suspend.
- TV Movie/Series behavior remains outside this policy via BuildConfig.IS_TV_BUILD and continues to be delegated to TvPlaybackLifecyclePolicy.
- Offline Movie/Series playback is covered because offline requests retain the same PlaybackMediaKind.MOVIE or PlaybackMediaKind.SERIES_EPISODE kinds.
