Audit findings
1. Product/UI retirement was already in place.
- Settings has no Device Sync destination or pairing UI.
- OwnPlay runtime bootstrap does not start a pairing coordinator, Device Sync coordinator, or transport session.
- SourceSyncState is playlist/source refresh state and is unrelated to retired cross-device Device Sync.

2. Runtime write-through was still present.
Normal local product mutations still wrote retired device_sync_* metadata through DeviceSyncLocalMutationWriter:
- source create / rename / delete;
- favorite add/remove/reorder;
- manual channel ordering;
- channel hide/unhide;
- local channel display-name edits;
- custom group create/rename/delete and membership edits.

3. Retired feature implementation was still compiled.
The source tree still contained historical cross-device pairing, transport, merge, portable-secret encryption, secure source transfer, persistence orchestration, and dedicated tests.

4. Database compatibility boundary.
OwnPlayDatabase remains Room version 6 and contains historical device_sync_* entities/DAO plus MIGRATION_5_6.
Removing those tables/entities now would be a separate database/schema migration and is intentionally outside this cleanup.
Existing v6 installations must continue to open without destructive migration.
