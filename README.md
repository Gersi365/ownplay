# OwnPlay

OwnPlay is an Android-first media player and playlist organizer.

OwnPlay is **player software only**. It does not provide, sell, host, or distribute channels, playlists, subscriptions, or IPTV services. Users supply their own authorized media sources.

## Project status

Build-phase implementation is starting with the Android phone baseline defined by the authoritative OwnPlay product specification in the dedicated Google Drive project folder.

## Authoritative product source

`OwnPlay_SOURCE.md` in the dedicated OwnPlay Google Drive folder is the authoritative product/source specification. GitHub is the authoritative source for application code and implementation history.

No production deployment or store publication is implied by this repository state.
